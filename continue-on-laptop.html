Mosh · CQ Popup QA Agent

Продолжить работу
на ноутбуке

Синхронизация через git. Пять шагов — и можно кодить дальше на любой машине.

1
Клонировать репозиторий

Открой терминал в нужной папке и скачай проект с GitHub:

git clone https://github.com/alikin-lab/Mosh.git cd Mosh
2
Создать файл .env
⚠️
Важно: файла .env в git нет — в нём токен доступа, и он намеренно не коммитится. На новой машине его нужно создать вручную.

Создай файл .env в корне проекта с таким содержимым:

CQ_AUTH_TOKEN=app.2782.687ba9bc168ca3274fe0a9ad2e3a2920035af5c055252e6d CQ_APP_ID=2782
3
Установить зависимости

Python-пакеты и браузер для Playwright:

pip install -r requirements.txt playwright install chromium
4
Проверить запуск

Тестовый прогон на 60 секунд с видимым браузером:

python -m agent.test_runner --url https://bitrix.carrotquest.ru --duration 60 --no-headless --http-user carrotadmin --http-pass "128BV3xJ00GMuxS1pFFHuLAP"
🔑
Пароль basic-auth передаётся прямо в команде и в git тоже не хранится. Держи его под рукой.
5
Рабочий цикл между машинами

Чтобы изменения не терялись при переходе с компьютера на ноут и обратно:

↓ Перед работой

git pull

↑ После работы

git add -A git commit -m "что сделал" git push
✅
Главное правило: pull в начале, push в конце. Тогда обе машины всегда в актуальном состоянии.
— Опционально, на потом —
🌍
Сервер в Германии

Для самой разработки сервер не нужен — только git. Но он пригодится, когда захочешь:

🌐
Выложить презентацию по ссылке — чтобы команда и жюри открыли её в браузере без скачивания.
🤖
Гонять агента в фоне — Linux-сервер удобнее для headless-прогонов и запусков по расписанию.
