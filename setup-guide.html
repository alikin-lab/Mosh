🚀 Запуск Mosh в AntiGravity

Агент для тестирования попапов Carrot Quest

⬡ github.com/alikin-lab/Mosh
1

Открыть репозиторий в AntiGravity

  1. Открыть AntiGravity
  2. На стартовом экране нажать Clone Repository
  3. Вставить ссылку и нажать Enter:
https://github.com/alikin-lab/Mosh
  • Дождаться завершения клонирования.
    • 2

    Создать файл .env с токенами

    В корне проекта (рядом с requirements.txt) создать файл .env и вставить токены — получить у Евгения:

    CQ_AUTH_TOKEN=app.2782.xxxxxxxxxxxxxxxx
CQ_APP_ID=2782
    ⚠️ Файл .env не хранится в git — создать вручную на каждой машине.
    3

    Установить зависимости

    Открыть терминал в AntiGravity и выполнить по очереди:

    pip install -r requirements.txt
playwright install chromium

    Установка занимает ~1–2 минуты.

    4

    Запустить тест

    Написать агенту в чат AntiGravity на русском:

    Запусти тест попапов на сайте https://bitrix.carrotquest.ru,
легенда: потенциальный клиент хочет купить продукт,
длительность 3 минуты

    Или запустить вручную из терминала:

    python -m agent.test_runner \
  --url https://bitrix.carrotquest.ru \
  --scenario "Потенциальный клиент, хочет купить продукт" \
  --duration 120
    5

    Читать отчёт

    Через 2 минуты агент выведет отчёт в чат:

    ## 🔍 Отчёт тестирования попапов Сайт: https://bitrix.carrotquest.ru Длительность: 120 сек ID пользователя CQ: `4829301` --- ## 🐛 Найдено багов: 2 ### 🔴 Баг 1: Наложение попапов [11:30:15] - Одновременно видны 2 попапа - Попапы: CQ Попап (конструктор), JS Попап ### ⚠️ Баг 2: Быстрое повторное появление [11:30:45] - Интервал: 5.2 сек (порог: 60 сек) --- ## 📋 Хронология событий | Время | Событие | |----------|--------------------------------------| | 11:30:00 | Переход: https://bitrix.carrotquest.ru | | 11:30:10 | Появился: CQ Попап (конструктор) | | 11:30:15 | Появился: JS Попап ⚠️ БАГ | --- ## 👤 Карточка пользователя 🔗 Открыть карточку в Carrot Quest
    ?

    Если что-то не работает

    Проблема Решение
    ModuleNotFoundError: playwright Повторить pip install -r requirements.txt
    Executable doesn't exist Повторить playwright install chromium
    CQ_AUTH_TOKEN не задан Проверить файл .env в корне проекта
    Браузер не открывается визуально Добавить флаг --no-headless в команду
